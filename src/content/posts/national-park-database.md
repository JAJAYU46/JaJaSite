## Overview

This relational database project organizes information about U.S. national parks. Its data model covers national parks, species, anomaly reports, and environmental records.

## Implementation

The project uses MySQL for relational storage, Python for importing data and connecting to the database, and a Streamlit map interface for exploring the information. The public report documents operational records for crime incidents, employees, environmental conditions, visitors, and species-related reports, alongside parks, species, and a park–species junction table. Entity-count terminology differs between the short source record and the report, so no unresolved count is presented as a settled fact.

## My Contributions

I designed part of the tables and relationships and implemented Python data import, database connections, and the Streamlit map interface. The original source explicitly identifies these responsibilities.

## Technologies

MySQL, Python, Streamlit, and relational database design.

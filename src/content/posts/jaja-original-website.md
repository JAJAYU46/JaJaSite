## Overview

My original portfolio website used a spreadsheet-backed publishing workflow to make project updates easier. It is a separate project from this Astro-based JaJaSite portfolio.

## Implementation

The frontend was built with HTML and CSS. JavaScript and Google Apps Script connected the website to project data in Google Sheets. New project blocks could be added through the website's first block, or their data could be edited directly in the spreadsheet. The original site was published through GitHub Pages.

## Technologies

HTML, CSS, JavaScript, Google Apps Script, Google Sheets, and GitHub Pages.

## Overview

This project explores how a mobile robot can help library users find books by navigating to the requested shelf. It is separate from the indoor object-search project.

## Implementation

The system integrates SLAM and navigation within a ROS architecture on a Scout Mini mobile robot. Its intended workflow is autonomous travel to a target bookshelf. The public report describes a simulation-to-hardware workflow using ROS Melodic, Ubuntu 18.04, and Gazebo, followed by testing in a controlled physical environment.

The report discusses velocity calibration to reduce overshoot and increased CPU load during physical deployment. Evaluation was internal to the four-person team, rather than a large-scale user study. A demonstration, a presentation video, and the full project report are preserved in Resources.

## My Contributions

I collaborated with three teammates on integrating the SLAM and navigation system. The source does not identify a finer division of responsibilities, so individual module ownership is not assigned here.

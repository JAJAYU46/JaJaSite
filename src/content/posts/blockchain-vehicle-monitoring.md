## Overview

A four-person team developed a vehicle-state recording system using cameras and accelerometer measurements from a model vehicle. Measurements were stored in a database and on a blockchain for review and integrity checking.

## Implementation

The project combines sensor data collection with stored records and a Streamlit interface for reviewing historical data. Blockchain verification provides a way to check the integrity of the recorded information. The public report identifies an IOTA upload path and AES encryption modules in the backend. Its Raspberry Pi sensor module collects measurements and passes data to the backend and database. No consensus mechanism is inferred from the module listing.

## My Contributions

I developed the user interface and blockchain-verification functionality. These responsibilities are explicitly identified in the original project record; the complete sensing and recording system was team work.

## Technologies

Streamlit, Python, sensor data collection, database storage, and blockchain verification.
